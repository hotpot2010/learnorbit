# 知识点提取功能说明

## 功能概述

针对教学视频的 Bilibili 批量分析，现已优化为**智能知识点提取**模式：

1. **ASR 识别**：提取带时间戳的逐字稿
2. **智能分段**：长视频自动分段（每段约 8000 字符）
3. **并行处理**：多段同时调用 LLM 提取知识点
4. **结果汇总**：自动去重并按时间排序

## 输出格式

```json
{
  "knowledge_points": [
    {
      "name": "函数定义",
      "start_time": "00:15",
      "end_time": "02:30"
    },
    {
      "name": "变量作用域",
      "start_time": "02:35",
      "end_time": "05:20"
    }
  ]
}
```

## 特点

### 1. 智能过滤
- 只提取明确的**知识点**
- 自动过滤：闲聊、过渡语、重复内容、非教学内容

### 2. 时间精准
- 每个知识点都有准确的开始和结束时间
- 基于 ASR 的逐字稿时间戳

### 3. 高效处理
- 长视频自动分段
- 多段并行调用 LLM（3倍速度提升）
- 智能去重和排序

### 4. 简洁输出
- 知识点名称简洁（≤10字）
- 纯 JSON 格式，无冗余信息
- 单一层级，易于解析

## 技术架构

```
视频 URL
  ↓
下载视频
  ↓
上传到文件服务器
  ↓
ASR 识别（带时间戳）
  ↓
智能分段（8000字符/段）
  ↓
并行调用 LLM（多段同时处理）
  ├─ 段1 → 提取知识点
  ├─ 段2 → 提取知识点
  └─ 段3 → 提取知识点
  ↓
汇总 + 去重 + 排序
  ↓
JSON 输出
```

## Prompt 优化

系统使用的优化 Prompt：

```
请分析以下教学视频的逐字稿片段，提取其中的【知识点】。

要求：
1. 只提取明确的知识点，不要包含闲聊、过渡语、重复内容
2. 每个知识点必须包含准确的开始和结束时间
3. 知识点名称要简洁明确（10字以内）
4. 按时间顺序排列
5. 以 JSON 格式输出

逐字稿片段（时间范围：XX:XX - XX:XX）：
[带时间戳的逐字稿]

请以以下 JSON 格式输出：
{
  "knowledge_points": [
    {
      "name": "知识点名称",
      "start_time": "MM:SS",
      "end_time": "MM:SS"
    }
  ]
}

注意：
- 只输出 JSON，不要其他说明文字
- 如果没有明确的知识点，返回空数组
```

## 性能优化

### 分段策略
- **自动分段**：每段最多 8000 字符
- **时间对齐**：按 ASR 时间戳分段，不切断句子

### 并行处理
- **asyncio.gather**：所有段同时处理
- **速度提升**：30 分钟视频约 3-5 分钟完成

### 去重算法
- 基于 `(名称, 开始时间)` 作为唯一标识
- 自动按时间排序

## 缓存机制

### ASR 缓存
- 相同视频只需 ASR 一次
- 缓存带时间戳的完整逐字稿
- 大幅节省 ASR API 调用

### 文件位置
```
backend/
  cache/
    asr_*.json          # ASR 逐字稿缓存
    cache_index.json    # 缓存索引
```

## 依赖服务

1. **ASR 服务**：`tech.baijia.com/ai/tool/asr`
2. **LLM 服务**：`llm.baijia.com` (百家接口)
   - 模型：`claude-4.5-sonnet`
3. **文件服务器**：`file.gsxservice.com`

## 错误处理

- 单段失败不影响其他段
- 异常会被捕获并记录
- 返回已成功提取的知识点
