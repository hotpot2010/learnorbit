# 视频分析处理流程说明

## 🎬 完整流程概览

从用户点击"开始学习"到看到分析结果，完整流程如下：

```
1. 删除临时下载文件 (< 1秒)
   ↓
2. 📤 上传视频到文件服务器 (30秒 - 3分钟)  ⚠️ 最耗时的步骤
   ├─ 5MB 视频: ~10-30秒
   ├─ 20MB 视频: ~40-120秒
   └─ 50MB 视频: ~2-5分钟
   ↓
3. 🎬 开始视频分析
   ↓
4. 🔍 检查 ASR 缓存 (< 1秒)
   ├─ 如果有缓存 → 跳到步骤7
   └─ 如果无缓存 → 继续
   ↓
5. 📝 创建 ASR 识别任务 (1-2秒)
   ↓
6. ⏳ 等待 ASR 完成 (视频时长 × 0.2 ~ 0.5)
   ├─ 3分钟视频: 30-90秒
   ├─ 10分钟视频: 2-5分钟
   └─ 30分钟视频: 6-15分钟
   ↓
7. 📚 提取知识点 (10-30秒)
   └─ 使用 LLM 分析逐字稿，并行处理长文本
   ↓
8. ✅ 返回分析结果
```

## ⏱️ 各阶段时间估算

### 阶段 0: 文件清理
- **时间**: < 1秒
- **日志**: `Deleting original file ...`
- **说明**: 删除下载的临时视频文件

### 阶段 1: 视频上传 ⚠️ **最耗时**
- **时间**: 30秒 - 3分钟（取决于文件大小和网络速度）
- **日志**: 
  ```
  📤 Uploading local video to file server
  📤 Uploading file: temp_xxx.mp4
     File size: 55.22 MB
     This may take 110 - 276 seconds...
  ✅ Upload completed in 45.3s
  ```
- **影响因素**:
  - 视频文件大小
  - 网络上传速度
  - 文件服务器处理速度
- **优化建议**:
  - 使用分片上传
  - 添加上传进度条
  - 使用更快的CDN服务

### 阶段 2: 开始分析
- **时间**: < 1秒
- **日志**: `🎬 Starting video analysis...`
- **说明**: 初始化分析流程

### 阶段 3: ASR 识别
- **时间**: 视频时长 × 0.2 ~ 0.5（ASR 处理比实时快2-5倍）
- **日志**:
  ```
  📝 Step 1: ASR Recognition
  ✅ ASR task created: xxx-xxx-xxx
  ⏳ Waiting for ASR completion...
  ✅ Transcript extracted (12345 chars)
  ```
- **优化**: 
  - 如果视频已分析过，直接使用缓存（< 1秒）
  - 缓存有效期: 7天

### 阶段 4: 知识点提取
- **时间**: 10-30秒（取决于逐字稿长度）
- **日志**:
  ```
  📚 Step 2: Knowledge Point Extraction
  ✅ Knowledge points extracted: 15
  ```
- **说明**: 使用 LLM 分析逐字稿，提取结构化知识点
