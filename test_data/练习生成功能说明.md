# 离线视频练习生成功能说明

## 功能概述

为 offline video 的每个知识点自动生成练习题，支持数学和编程两种类型。

## 实现细节

### 1. 调用逻辑（参考知识点截图）

练习生成在 `execute_step_screenshots` 步骤中执行，与截图生成并行：

```python
# 在知识点提取完成后
# 1. 生成截图
screenshots = await self._generate_screenshots_for_video(...)

# 2. 生成练习题（新增）
exercises = await self._generate_exercises_for_knowledge_points(
    knowledge_points,
    asr_text,
    video_title,
    locale,
    subject="math"  # 或 "programming"
)

# 3. 将练习合并到知识点数据中
for kp_idx, kp in enumerate(knowledge_points):
    if kp_idx < len(exercises):
        kp["exercise"] = exercises[kp_idx]
```

### 2. Prompt 和格式（参考 video notes 练习功能）

#### 数学题型 Prompt（中文）

```python
prompt = f"""你是一位资深的数学教师，需要根据以下视频知识点生成一道练习题。

知识点名称：{kp_name}
知识点内容：{transcript_segment}

请生成一道练习题，要求：
1. 题型：随机选择【选择题】或【填空题】其中之一
2. 难度：适配中考/高考水平，有一定区分度
3. 题目要结合视频中讲解的具体知识点
4. 题目要有实际应用价值，不要过于简单
5. 如果有公式，使用 LaTeX 格式（用 $ 包裹），**注意：JSON中反斜杠必须转义，写成双反斜杠 \\\\ 例如 \\\\frac、\\\\sin**
6. 提供详细的解析和解题步骤

请以 JSON 格式返回，格式如下：

**选择题格式：**
{{
  "type": "multiple_choice",
  "title": "知识点练习：{kp_name}",
  "description": "根据视频内容，完成以下练习题",
  "difficulty": "intermediate",
  "question": "题目内容（LaTeX公式示例：$\\\\frac{{1}}{{2}}$ 或 $\\\\sin x$）",
  "choices": [
    {{"label": "A", "content": "选项A内容"}},
    {{"label": "B", "content": "选项B内容"}},
    {{"label": "C", "content": "选项C内容"}},
    {{"label": "D", "content": "选项D内容"}}
  ],
  "answer_type": "single",
  "solution": "B",
  "hints": ["提示1", "提示2", "提示3"]
}}

**填空题格式：**
{{
  "type": "fill_blank",
  "title": "知识点练习：{kp_name}",
  "description": "根据视频内容，完成以下练习题",
  "difficulty": "intermediate",
  "question": "题目内容，用 ___ 表示填空位置（LaTeX示例：$\\\\frac{{1}}{{2}}$）",
  "blanks": 2,
  "answer_type": "text",
  "solution": "答案1;答案2",
  "hints": ["提示1", "提示2", "提示3"]
}}

只返回 JSON，不要其他说明文字。"""
```

#### 输出格式

**选择题示例：**
```json
{
  "type": "multiple_choice",
  "title": "知识点练习：勾股定理",
  "description": "根据视频内容，完成以下练习题",

  "choices": [
    {"label": "A", "content": "5"},
    {"label": "B", "content": "6"},
    {"label": "C", "content": "7"},
    {"label": "D", "content": "8"}
  ],
  "answer_type": "single",
```

**填空题示例：**
```json
{
  "type": "fill_blank",
  "title": "知识点练习：二次函数顶点式",
  "description": "根据视频内容，完成以下练习题",
  "difficulty": "intermediate",
  "question": "二次函数 $y = (x-2)^2 + 3$ 的顶点坐标是 ___，对称轴方程是 ___。",
```

### 3. 数据存储

练习数据存储在两个地方：

#### 3.1 独立的练习文件

```
{task_id}_exercises_p{part_number}.json  # 多P视频
{task_id}_exercises.json                 # 单P视频
```

文件格式：
```json
{
  "exercises": [
    {
      "type": "multiple_choice",
      "title": "...",
      ...
    },
    {
      "type": "fill_blank",
      "title": "...",
      ...
    }
  ],
  "count": 5
}
```

#### 3.2 任务数据库字段

在 `OfflineVideoTask` 表中新增字段：
- `exercises_result_url`: 练习结果文件的 CDN URL（单P视频）
- 对于多P视频，练习 URL 存储在 `steps.screenshots.result.part_results` 中

```python
# 单P视频
task["exercises_result_url"] = "https://file.gsxservice.com/xxx_exercises.json"

# 多P视频
task["steps"]["screenshots"]["result"]["part_results"] = [
    {
        "part_number": 1,
        "status": "success",
        "result_url": "...",  # 截图URL
        "exercises_url": "...",  # 练习URL
        "exercises_count": 5
    },
    ...
]
```

## 配置选项

### 学科类型

在 `_generate_exercises_for_knowledge_points` 调用时指定：

```python
# 数学题型
exercises = await self._generate_exercises_for_knowledge_points(
    knowledge_points,
    asr_text,
    video_title,
    locale="zh",
    subject="math"  # 数学
)

# 编程题型
exercises = await self._generate_exercises_for_knowledge_points(
    knowledge_points,
    asr_text,
    video_title,
    locale="zh",
    subject="programming"  # 编程
)
```

### LLM 服务提供商

通过环境变量 `LLM_PROVIDER` 配置：

```bash
# 使用火山引擎（默认）
LLM_PROVIDER=volcano

# 使用百家云
LLM_PROVIDER=baijia
```

## 错误处理

练习生成失败不会影响整体流程：

1. **单个练习生成失败**：会添加错误占位符，继续生成其他练习
2. **全部练习生成失败**：截图步骤仍然成功，只是没有练习数据
3. **练习文件上传失败**：会记录警告，不影响截图步骤

## 前端集成

前端可以通过以下方式获取练习数据：

```typescript
// 1. 从任务数据中获取练习URL
const exercisesUrl = task.exercises_result_url; // 单P视频
// 或
const exercisesUrl = task.steps.screenshots.result.part_results[0].exercises_url; // 多P视频

// 2. 下载练习数据
const response = await fetch(exercisesUrl);
const data = await response.json();
const exercises = data.exercises; // 练习列表

// 3. 渲染练习题
exercises.forEach(exercise => {
  if (exercise.type === 'multiple_choice') {
    // 渲染选择题
  } else if (exercise.type === 'fill_blank') {
    // 渲染填空题
  }
});
```

## 性能优化

1. **并行生成**：多个知识点的练习题按顺序生成（因为需要调用 LLM）
2. **缓存机制**：可以考虑添加练习缓存（类似笔记缓存）
3. **异步处理**：练习生成不阻塞截图生成
