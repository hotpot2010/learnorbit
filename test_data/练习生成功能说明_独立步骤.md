# 离线视频练习生成功能说明（独立步骤）

## 📋 功能概述

练习生成已从截图步骤中独立出来，成为一个与截图平行的独立功能。客户可以单独运行练习生成步骤，不依赖截图步骤。

## 🔄 功能变更

### 之前（集成在截图步骤中）
- ❌ 练习生成在截图步骤中自动执行
- ❌ 无法单独控制练习生成
- ❌ 截图失败会影响练习生成

### 现在（独立步骤）
- ✅ 练习生成是独立的步骤（`exercises`）
- ✅ 可以单独执行，不依赖截图步骤
- ✅ 与截图步骤平行，互不影响
- ✅ 客户可以选择只生成练习，不生成截图

## 📁 步骤顺序

```
1. download       (下载视频)
   ↓
2. asr            (ASR 识别)
   ↓
3. knowledge_points (知识点提取)
   ↓
4a. screenshots   (生成截图) ← 可选
4b. exercises     (生成练习) ← 可选，独立运行
```

## 🚀 使用方法

### 1. 创建任务

```bash
curl -X POST "http://localhost:8000/api/offline-videos/tasks" \
  -H "Content-Type: application/json" \
  -d '{"bilibili_url": "https://www.bilibili.com/video/BV1xx411c7xC"}'
```

返回：
```json
{
  "success": true,
  "task_id": "task_1234567890_5678",
  "task": {
    "steps": {
      "download": {"status": "pending", ...},
      "asr": {"status": "pending", ...},
      "knowledge_points": {"status": "pending", ...},
      "screenshots": {"status": "pending", ...},
      "exercises": {"status": "pending", ...}  ← 新增步骤
    }
  }
}
```

### 2. 执行前置步骤

```bash
# 2.1 下载视频
curl -X POST "http://localhost:8000/api/offline-videos/tasks/{task_id}/steps/download/execute"

# 2.2 ASR 识别
curl -X POST "http://localhost:8000/api/offline-videos/tasks/{task_id}/steps/asr/execute"

# 2.3 知识点提取
curl -X POST "http://localhost:8000/api/offline-videos/tasks/{task_id}/steps/knowledge_points/execute"
```

### 3. 单独执行练习生成步骤

```bash
# 3.1 生成数学练习题（默认）
curl -X POST "http://localhost:8000/api/offline-videos/tasks/{task_id}/steps/exercises/execute" \
  -H "Content-Type: application/json" \
  -d '{"subject": "math"}'

# 3.2 生成编程练习题
curl -X POST "http://localhost:8000/api/offline-videos/tasks/{task_id}/steps/exercises/execute" \
  -H "Content-Type: application/json" \
  -d '{"subject": "programming"}'
```

### 4. 查看执行结果

```bash
curl "http://localhost:8000/api/offline-videos/tasks/{task_id}"
```

返回：
```json
{
  "task_id": "task_xxx",
  "exercises_result_url": "https://file.gsxservice.com/task_xxx_exercises.json",
  "steps": {
    "exercises": {
      "status": "success",
      "progress": 100,
      "message": "✅ 练习生成完成（共5道练习题）",
      "result": {
        "result_url": "https://file.gsxservice.com/task_xxx_exercises.json",
        "exercises_count": 5,
        "knowledge_points_count": 5
      }
    }
  }
}
```

## 📊 多P视频支持

对于多P视频，练习生成支持 `continue` 和 `retry` 模式：

```bash
# continue 模式：只处理失败的分P
curl -X POST "http://localhost:8000/api/offline-videos/tasks/{task_id}/steps/exercises/execute?mode=continue" \
  -H "Content-Type: application/json" \
  -d '{"subject": "math"}'

# retry 模式：重新处理所有分P
curl -X POST "http://localhost:8000/api/offline-videos/tasks/{task_id}/steps/exercises/execute?mode=retry" \
  -H "Content-Type: application/json" \
  -d '{"subject": "math"}'
```

## 🔧 API 参数说明

### 执行练习生成步骤

**端点**: `POST /api/offline-videos/tasks/{task_id}/steps/exercises/execute`

**参数**:
- `task_id` (路径参数): 任务ID
- `subject` (请求体): 学科类型
  - `"math"`: 数学题型（选择题/填空题）
  - `"programming"`: 编程题型（填空/分步/选择/完整）
- `mode` (查询参数, 可选): 执行模式
  - `null`: 正常执行
  - `"continue"`: 只执行失败的分P
  - `"retry"`: 重新执行所有分P

**返回**:
```json
{
  "success": true,
  "message": "步骤 exercises 已开始执行"
}
```

## 📂 数据存储

### 单P视频

练习数据存储在：
- **文件**: `{task_id}_exercises.json`
- **CDN URL**: `task.exercises_result_url`
- **步骤结果**: `task.steps.exercises.result`

文件格式：
```json
{
  "exercises": [
    {
      "type": "multiple_choice",
      "title": "知识点练习：勾股定理",
      "question": "...",
      "choices": [...],
      "solution": "A",
      "hints": [...]
    },
    {
      "type": "fill_blank",
      "title": "知识点练习：二次函数",
      "question": "...",
      "solution": "...",
      "hints": [...]
    }
  ],
  "count": 5
}
```

### 多P视频

练习数据存储在：
- **文件**: `{task_id}_exercises_p{part_number}.json`
- **CDN URL 列表**: `task.exercises_result_url` (JSON 数组)
- **分P结果**: `task.steps.exercises.result.part_results`

步骤结果格式：
```json
{
  "result_urls": [
    "https://file.gsxservice.com/task_xxx_exercises_p1.json",
    "https://file.gsxservice.com/task_xxx_exercises_p2.json"
  ],
  "part_results": [
    {
      "part_number": 1,
      "status": "success",
      "result_url": "https://file.gsxservice.com/task_xxx_exercises_p1.json",
      "exercises_count": 5,
      "knowledge_points_count": 5
    },
    {
      "part_number": 2,
      "status": "success",
      "result_url": "https://file.gsxservice.com/task_xxx_exercises_p2.json",
      "exercises_count": 3,
      "knowledge_points_count": 3
    }
  ],
  "total_exercises": 8
}
```

## 🔍 依赖关系

练习生成步骤的前置条件：
1. ✅ 知识点提取步骤已完成（`knowledge_points` = `success` 或 `partial_success`）
2. ✅ 存在知识点结果URL（`knowledge_points_result_url` 不为空）
3. ✅ 存在ASR结果URL（`asr_result_url` 不为空，用于获取逐字稿）

**不依赖**：
- ❌ 截图步骤（`screenshots`）- 完全独立

## 🎯 使用场景

### 场景1：只需要练习题，不需要截图

```bash
# 执行前置步骤
curl -X POST ".../steps/download/execute"
curl -X POST ".../steps/asr/execute"
curl -X POST ".../steps/knowledge_points/execute"

# 只生成练习题，跳过截图
curl -X POST ".../steps/exercises/execute" \
  -d '{"subject": "math"}'
```

### 场景2：同时生成截图和练习题

```bash
# 执行前置步骤
curl -X POST ".../steps/download/execute"
curl -X POST ".../steps/asr/execute"
curl -X POST ".../steps/knowledge_points/execute"

# 并行生成截图和练习题
curl -X POST ".../steps/screenshots/execute" &
curl -X POST ".../steps/exercises/execute" \
  -d '{"subject": "math"}'
```

### 场景3：先生成截图，后生成练习题

```bash
# 先生成截图
curl -X POST ".../steps/screenshots/execute"

# 等截图完成后，再生成练习题
curl -X POST ".../steps/exercises/execute" \
  -d '{"subject": "math"}'
```

### 场景4：重新生成不同类型的练习题

```bash
# 先生成数学练习题
curl -X POST ".../steps/exercises/execute" \
  -d '{"subject": "math"}'

# 后来想换成编程练习题，重新生成
curl -X POST ".../steps/exercises/execute?mode=retry" \
  -d '{"subject": "programming"}'
```

## 🛠️ 前端集成示例

```typescript
// 1. 检查知识点步骤是否完成
const task = await fetch(`/api/offline-videos/tasks/${taskId}`).then(r => r.json());
const kpStatus = task.steps.knowledge_points.status;

if (kpStatus === 'success' || kpStatus === 'partial_success') {
  // 2. 执行练习生成
  const response = await fetch(
    `/api/offline-videos/tasks/${taskId}/steps/exercises/execute`,
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ subject: 'math' })
    }
  );
  
  // 3. 轮询检查执行状态
  const checkStatus = setInterval(async () => {
    const task = await fetch(`/api/offline-videos/tasks/${taskId}`).then(r => r.json());
    const exercisesStatus = task.steps.exercises.status;
    
    if (exercisesStatus === 'success') {
      clearInterval(checkStatus);
      
      // 4. 下载练习数据
      const exercisesUrl = task.exercises_result_url;
      const exercises = await fetch(exercisesUrl).then(r => r.json());
      
      console.log('练习题：', exercises.exercises);
      // 渲染练习题...
    } else if (exercisesStatus === 'failed') {
      clearInterval(checkStatus);
      console.error('练习生成失败');
    }
  }, 2000);
}
```

## ⚡ 性能优化

1. **并行执行**：截图和练习题可以并行生成，互不影响
2. **按需生成**：客户可以选择只生成需要的内容
3. **独立重试**：练习生成失败不影响截图，可以单独重试
4. **模式控制**：使用 `continue` 模式可以避免重复生成已成功的分P

## 📌 注意事项

1. **依赖关系**：练习生成需要知识点提取步骤完成
2. **学科类型**：默认为 `math`，可以通过 `subject` 参数指定
3. **多P视频**：支持 `continue` 和 `retry` 模式
4. **错误处理**：单个练习生成失败不影响其他练习
5. **数据格式**：与 video notes 的练习格式完全一致
