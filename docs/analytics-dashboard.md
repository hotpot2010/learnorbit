# 数据统计分析页面使用说明

## 功能概述

数据统计分析页面提供了全面的用户行为分析功能，帮助了解用户的使用情况和转化路径。

## 访问地址

```
/analytics-dashboard
```

## 主要功能

### 1. 日期范围筛选

- **开始日期**：选择统计的起始日期
- **结束日期**：选择统计的结束日期（包含当天全天）
- **默认范围**：最近7天

### 2. 用户过滤

可以排除特定的用户ID，避免测试账号影响统计数据。

**默认排除的用户ID：**
- `KoGRueO3tCh6UOQrZOeTihCUpid7rWvY`
- `rHirWA0eUVV7wyBXlbTXLmgk0Hya6ql7`
- `XFTXYfkdLeLAvN5NFiObDqdNcu6VTzO0`

可以在输入框中修改或添加更多要排除的用户ID（用逗号分隔）。

### 3. 概览统计

显示三个关键指标：

- **总访问用户数**：在选定时间范围内有行为记录的唯一用户数
- **多天访问用户**：访问天数≥2天的用户数
- **留存率**：多天访问用户占总用户的百分比

### 4. 转化漏斗

展示用户行为的转化路径，分为三层：

#### 顶层
- 🎯 **生成课程**：作为基准（100%）

#### 中层（平级）
- 📚 **开始学习**：从生成课程到开始学习的转化率
- 🎬 **开始视频学习**：从生成课程到开始视频学习的转化率

#### 底层
- ⚡ **其他操作**：包括继续学习、视频搜索、视频提问、视频截图、视频练习等

每个阶段都显示：
- 用户数量
- 相对于顶层的转化百分比
- 可视化的进度条

### 5. 各操作用户统计

显示每个操作类型的用户数量：

- **生成课程** (generate_course)
- **开始学习** (start_learning)
- **继续学习** (continue_learning)
- **开始视频学习** (start_video_learning)
- **视频搜索** (video_search)
- **视频提问** (video_ask_question)
- **视频截图** (video_screenshot)
- **视频练习** (video_exercise)

### 6. 用户详情列表

显示所有用户的详细信息：

- **用户ID**：唯一标识符
- **访问天数**：该用户在选定时间范围内的访问天数
- **操作列表**：该用户执行过的所有操作类型

**特殊标记：**
- 多天访问用户会以绿色背景高亮显示
- 带有"多天访问"徽章

**搜索功能：**
- 可以通过用户ID搜索特定用户
- 支持模糊匹配

### 7. 数据导出

点击右上角的"导出数据"按钮，可以将用户详情导出为CSV文件，包含：
- 用户ID
- 访问天数
- 是否多天访问
- 操作列表

文件名格式：`analytics_[开始日期]_[结束日期].csv`

## 数据来源

统计数据来自 `key_actions` 表，该表记录了以下关键用户行为：

- 生成课程
- 开始学习
- 继续学习
- 开始视频学习
- 视频搜索
- 视频提问
- 视频截图
- 视频练习

## 权限说明

目前页面需要用户登录才能访问。如需更严格的权限控制（如仅管理员可访问），可以在代码中添加角色检查。

## API端点

统计数据通过以下API获取：

```
GET /api/analytics/stats?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD&excludeUserIds=id1,id2,id3
```

**参数说明：**
- `startDate`：开始日期（必填）
- `endDate`：结束日期（必填）
- `excludeUserIds`：要排除的用户ID列表，用逗号分隔（可选）

## 技术实现

### 后端
- **框架**：Next.js API Routes
- **数据库**：PostgreSQL (Drizzle ORM)
- **查询优化**：使用 SQL 聚合函数减少数据传输

### 前端
- **框架**：React + Next.js
- **UI组件**：Shadcn UI
- **样式**：Tailwind CSS
- **可视化**：自定义进度条（漏斗图）

## 性能优化建议

1. **日期范围**：建议查询范围不超过30天，以保证查询性能
2. **缓存**：可以考虑在API层添加缓存（如Redis），减少数据库查询
3. **分页**：如果用户数量很大，可以为用户详情列表添加分页功能

## 未来扩展
