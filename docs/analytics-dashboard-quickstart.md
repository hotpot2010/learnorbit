# 数据统计分析页面 - 快速开始

## 快速访问

1. 启动开发服务器：
```bash
npm run dev
# 或
pnpm dev
```

2. 在浏览器中访问：
```
http://localhost:3000/analytics-dashboard
```

## 测试API

运行测试脚本验证API是否正常工作：

```bash
npm run test-analytics
# 或
pnpm tsx scripts/test-analytics-api.ts
```

## 基本使用流程

### 1. 选择日期范围

默认显示最近7天的数据，你可以：
- 点击"开始日期"选择起始日期
- 点击"结束日期"选择结束日期
- 点击"查询统计"按钮刷新数据

### 2. 查看概览统计

页面顶部显示三个关键指标卡片：
- **总访问用户数**：在选定时间范围内的唯一用户数
- **多天访问用户**：访问≥2天的用户数（高价值用户）
- **留存率**：多天访问用户占比

### 3. 分析转化漏斗

转化漏斗展示了用户行为的转化路径：

```
🎯 生成课程 (100%)
    ↓
    ├─ 📚 开始学习 (XX%)
    └─ 🎬 开始视频学习 (XX%)
        ↓
        ⚡ 其他操作 (XX%)
```

每个阶段显示：
- 用户数量
- 转化率（相对于顶层）
- 可视化进度条

### 4. 查看用户详情

用户详情列表显示每个用户的：
- 用户ID
- 访问天数
- 执行的操作列表

**特别注意：**
- 多天访问用户以绿色背景高亮显示
- 可以使用搜索框快速查找特定用户

### 5. 导出数据

点击右上角"导出数据"按钮，下载CSV文件进行进一步分析。

## 常见问题

### Q: 为什么没有数据？

A: 可能的原因：
1. 数据库中还没有用户行为记录
2. 选择的日期范围内没有数据
3. 所有用户都被排除了

解决方法：
- 扩大日期范围
- 清空"排除用户ID"输入框
- 确认 `key_actions` 表中有数据

### Q: 如何查看特定用户的行为？

A: 
1. 在用户详情列表的搜索框中输入用户ID
2. 或者清空"排除用户ID"，只保留你想查看的用户ID

### Q: 转化率为什么是0%？

A: 如果"生成课程"的用户数为0，所有转化率都会显示为0%。这是正常的，说明在选定时间范围内没有用户生成课程。

### Q: 如何添加新的操作类型？

A: 
1. 在前端代码中添加新的事件追踪（使用 `trackKeyActionSafely`）
2. 更新 `EVENT_NAMES` 映射（在 `analytics-dashboard/page.tsx` 中）
3. 数据会自动显示在统计页面中

## 数据说明

### 多天访问用户的定义

访问天数 ≥ 2 天的用户被认为是"多天访问用户"。这些用户通常是高价值用户，值得重点关注。

### 漏斗层级说明

- **顶层（生成课程）**：用户的首次核心行为，作为基准
- **中层（开始学习/开始视频学习）**：用户开始使用产品的核心功能
- **底层（其他操作）**：用户的深度使用行为

### 操作类型说明

| 操作类型 | 说明 |
|---------|------|
| generate_course | 用户生成了一个课程 |
| start_learning | 用户开始学习课程 |
| continue_learning | 用户继续学习课程 |
| start_video_learning | 用户开始视频学习 |
| video_search | 用户搜索视频 |
| video_ask_question | 用户在视频中提问 |
| video_screenshot | 用户截取视频截图 |
| video_exercise | 用户完成视频练习 |
