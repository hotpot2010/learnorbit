# 视频笔记原型页面

这是一个基于"视频笔记说明"设计的完整功能原型页面，展示了视频学习和智能笔记的核心功能。

## 🎯 访问地址

- 开发环境: `http://localhost:3000/zh/video-notes-prototype`
- 或: `http://localhost:3000/en/video-notes-prototype`

## ✨ 核心功能

### 1. 系列视频搜索/推荐/介绍 📚
- ✅ 课程信息卡片展示（标题、评分、学生数、时长）
- ✅ 课程特点和难度标识
- ✅ 课程目标和收益介绍
- ✅ 标签系统（React, JavaScript 等）
- ✅ 顶部搜索和收藏功能

### 2. 视频解析 🎬
- ✅ **导图导航**: 章节列表可切换为导图视图（点击"🗺️ 导图"按钮）
- ✅ **切片定位**: 点击任意章节快速跳转到对应视频片段
- ✅ **关联切片**: 每个笔记都关联到对应的视频时间点和章节

### 3. 多种测验 📝
- ✅ **选择填空**: 📝 选择题类型的测验
- ✅ **代码编程**: 💻 编程题类型（显示为 coding 类型）
- ✅ **低代码编程**: 支持（可扩展）
- ✅ **模拟面试**: 🎤 面试问答题
- ✅ **口语练习**: 支持（可扩展）
- ✅ 测验完成状态追踪（绿色 ✓ 标记）

### 4. 笔记/提问 ✍️
- ✅ **AI回答拖动到笔记**: 点击"AI提示"按钮与AI对话，回答可添加到笔记
- ✅ **关联切片拖动到笔记**: 
  - 逐字稿卡片可以直接拖拽到右侧笔记区域
  - 或点击"+"按钮快速添加
- ✅ **插入便签**: 点击"便签"按钮可插入自定义便签
- ✅ **导出/分享笔记**: 
  - 📥 导出 PDF
  - 📱 分享到小红书
  - 💾 下载笔记
- ✅ **一键导出**: 底部快速操作栏提供快捷导出

## 🎨 学习体验

### 左右分屏布局
```
┌─────────────────────────────────┬─────────────────┐
│                                 │                 │
│   视频播放器 (16:9)             │   我的笔记 📝    │
│   - 播放控制                    │   - AI聊天      │
│   - 进度条                      │   - 笔记列表    │
│   - 章节导航                    │   - 快速操作    │
│                                 │                 │
├─────────────────────────────────┤                 │
│                                 │                 │
│   逐字稿 / 测验                 │                 │
│   - 可拖拽到笔记                │                 │
│   - 时间戳定位                  │                 │
│                                 │                 │
└─────────────────────────────────┴─────────────────┘
```

### 交互特性

1. **视频转图文笔记**:
   - 逐字稿实时显示，可高亮重点
   - 一键添加到笔记
   - 导图模式可视化课程结构

2. **先看视频，再复习 VS 直接通过笔记**:
   - 章节完成状态追踪（绿色勾选标记）
   - 笔记关联到视频时间点，可快速跳转回放

3. **左右分屏，随视频播放**:
   - 左侧视频+逐字稿
   - 右侧实时记录笔记
   - 拖拽交互流畅

4. **上半部分主视频，下半部分逐字稿**:
   - 视频播放器在上方，带完整播放控制
   - 逐字稿在下方，带时间戳和高亮
   - 可切换到测验模式

5. **逐字稿和视频截图可添加到笔记**:
   - 鼠标悬停显示"+"按钮
   - 拖拽功能（抓取图标：`GripVertical`）
   - 自动关联时间戳和章节

### 组件和库
- React Hooks (`useState`)
- Lucide Icons (丰富的图标库)

- 自定义字体系统 (`getFontFamily`)

```typescript

- mockQuizzes: 测验题目（3种类型）

```

## 💡 使用提示

1. **拖拽体验**: 
   - 鼠标悬停在逐字稿上看到 `⋮⋮` 图标
   - 按住并拖拽到右侧笔记区域
   - 松开鼠标完成添加

2. **快速添加**:
   - 点击逐字稿卡片右上角的"+"按钮
   - 直接添加到笔记，无需拖拽

3. **AI交互**:
   - 点击笔记区域的消息图标展开AI聊天
   - 输入问题获取AI回答
   - AI回答可以添加到笔记

4. **导出笔记**:
   - 顶部工具栏的"导出笔记"按钮
   - 笔记区域底部的快速链接
   - 支持 PDF 和小红书格式
